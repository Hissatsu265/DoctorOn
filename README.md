# DoctorOn

A smart health monitoring application integrating IoT and AI technologies

## 📝 Overview

DoctorOn is part of a comprehensive health monitoring system consisting of 3 main components:
- 📱 Mobile Application (Current Repository)
- 🔌 IoT Device Code
- 🤖 AI Model Code

The application is developed in Kotlin, focusing on monitoring and analyzing user health through data collected from IoT devices.

## ✨ Key Features

### 📊 Health Monitoring
- Real-time heart rate data display
- Health data analysis and visualization
- History tracking and storage

### 🤖 Health Predictions
- Health trend analysis
- Early risk warnings
- Health improvement suggestions

### 👨‍⚕️ Medical Connectivity
- Direct communication with doctors
- Consultation scheduling
- Health data sharing

## 🛠️ Technologies Used

- Kotlin
- Android Jetpack Components
- Room Database
- Retrofit
- MVVM Architecture
- Coroutines
- LiveData
- ViewModel

## 📱 System Requirements

- Android 6.0 (API level 23) or higher
- Internet connection
- Bluetooth for IoT device connectivity

## ⚙️ Installation

1. Clone the repository:
```bash
git clone https://github.com/Hissatsu265/DoctorOn.git
```

2. Open the project in Android Studio

3. Sync Gradle and build the project

4. Run the application on a device or emulator
